# 🐾 Pata Viva — Plataforma Web para ONG

A **Pata Viva** é um projeto acadêmico de desenvolvimento web que tem como objetivo apresentar uma organização dedicada à proteção animal, divulgar projetos sociais e incentivar o voluntariado e a adoção responsável de cães e gatos.

O projeto foi desenvolvido como parte da disciplina de desenvolvimento web, aplicando conceitos de HTML5 semântico, CSS3, responsividade, acessibilidade e organização de código.

## 🎯 Objetivo

Criar uma presença digital organizada e acessível para a ONG Pata Viva, facilitando o acesso às informações institucionais, aos projetos sociais e ao cadastro de pessoas interessadas em contribuir com a causa animal.

## 📄 Páginas do projeto

- **Página inicial (`index.html`):** apresenta a organização, sua história, missão, valores, impacto e informações de contato.
- **Projetos sociais (`projetos.html`):** apresenta os projetos e as formas de participação, voluntariado e apoio à organização.
- **Cadastro (`cadastro.html`):** disponibiliza um formulário para coleta de informações de pessoas interessadas em se cadastrar.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação semântica das páginas e dos formulários.
- **CSS3:** estilização, identidade visual, layouts e adaptação para diferentes tamanhos de tela.
- **JavaScript:** suporte a funcionalidades interativas do projeto, conforme implementadas nos arquivos da aplicação.
- **Git e GitHub:** versionamento do código e colaboração entre os integrantes do grupo.

## ♿ Acessibilidade e responsividade

O projeto busca utilizar elementos HTML semânticos, hierarquia lógica de títulos, formulários organizados e estilos adaptáveis a diferentes dispositivos.

A acessibilidade e a responsividade devem ser verificadas durante os testes da aplicação, considerando navegação por teclado, legibilidade, contraste e comportamento em telas menores.

## ✅ Validação HTML

Os três documentos HTML foram verificados pelo **W3C HTML Checker**:

- `index.html`
- `projetos.html`
- `cadastro.html`

Os resultados registrados não apresentaram erros nem avisos. As evidências estão disponíveis em [`docs/validacao-html/`](docs/validacao-html/).

Ferramenta utilizada: [W3C HTML Checker](https://validator.w3.org/nu/).

## 🚀 Como executar o projeto

1. Clone o repositório ou baixe os arquivos do projeto.
2. Abra a pasta `ong-connect` no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador ou utilize uma extensão de servidor local, como o Live Server.
4. Navegue pelas páginas usando os links do site.
